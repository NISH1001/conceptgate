τ (tau) — the fire threshold
Fire only when LLR > τ. Calibrated, not guessed: τ = 3.0 ≈ “evidence 3σ beyond typical benign” ≈ 0.1% false alarms. Raise τ → stricter; lower → more sensitive.
J — the mixture size
How many (μ, Σ) components a class's Set((μ,Σ)) holds. J = 1: one Gaussian. J = 2: two modes. Chosen per class by BIC from the data — 12 samples afford J = 1.

Press run: the thought travels M's 12 blocks. At blocks 4–8 the taps light up with the prompt's actual loudness values, G blends them into a verdict, and the output either flows on or gets guardrailed. M is never modified — G only reads (and, in reroute mode, adds a vector).

⌕ anatomy of one loudness number — click a tap above, or pick a block

Where does a tap's loudness number come from? A dot product: the tap's 768-number activation z, times that mic's 768 tuning weights w, summed into one number. Real values below — the 12 heaviest of the mic's 768 weights, for the selected prompt.

Tap & flatten the loud dimensions

data.py · extract_token_activations → gate.py · _fit_directions

At each tapped block, G reads the last token's 768-number residual-stream vector. A few dimensions are naturally huge and would drown every dot product, so each (layer, dimension) is standardized:

z = (a − μ₀) / σ₀ μ₀, σ₀ = per-(layer, dim) mean & spread over the 24 fit prompts · plain numpy, gate.py:37-41

spread of the 12 loudest dimensions (blocks 4–8 pooled) — real values

Tune each microphone

concept_bank.py · fit_directions

The concept's signature at each layer is just an arrow between two averages — estimating averages is why ~12 examples suffice. No backprop anywhere:

wℓ = normalize( mean(harmful) − mean(benign) ) one unit vector in 768-D per tapped layer → W [5 × 768] · quality per mic = d′ = class-gap ÷ spread

discriminability d′ per tapped block — all five above 3 (≈2 is already strong)

Decide: which Set((μ, Σ)) explains it better?

mixture.py · select_gmm → gate.py · ConceptGate.llr

Each class owns a density over spectrogram space — a set of (μ, Σ) components. The verdict is a likelihood ratio against the calibrated threshold τ:

LLR(s) = log p(s | harmful) − log p(s | benign)  → 
BIC = −2·fit + k·ln N — every parameter pays rent 2nd component costs Δk = 21 params → rent 21·ln 12 ≈ 52; 12 samples can't pay it → J = 1. In stage 6, N = 8000 with a truly two-voiced class → rent paid instantly → J = 2.

Act: cut the call, or bend the thought

guard.py · Guard.generate → hooks.py · SteeringHooks

Abort — stop decoding, emit [GUARDRAILED]; remaining compute skipped. Reroute — add −α·w into the residual stream at the taps: the same arrow that detects the concept, pushed in reverse, steers M away while it keeps generating its own words. Remove the hooks → stock GPT-2 back. That's the adapter promise.

reroute: aℓ ← aℓ − α·wℓraw detection and steering share one learned object — a classifier head can score, but has nothing to inject

Why a set of (μ, Σ)? The case one Gaussian can't solve

scripts/toy_csg_mixture.py · synthetic “kill-shot”, labeled as such

Construct a world where benign has two voices flanking harmful (benign at −2 and +2, harmful at 0). One filtered score + one threshold can't carve out “the middle” — the scalar baseline sits near chance. The mixture picks J = 2 for benign and separates. Same taps, same directions — only the density model differs.
